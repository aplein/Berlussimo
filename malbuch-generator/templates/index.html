Prüfe Fooocus-Verbindung …

„Erstelle mir [Anzahl] Bilder [Thema] in diesem Stil mit folgendem Text auf der Seite [Text].“

🎨 Stil anpassen (optional)

Eine Vorlage oben wählen füllt diese Felder – du kannst sie dann frei ändern. So steuerst du den Look direkt hier, ohne den Code anzufassen.

🖼️ Beispielbild als Vorlage (optional)

Lade ein Bild hoch, an dem sich Fooocus orientiert – dann entstehen neue Motive in ähnlichem Look.

📖 Geschichte erzählen / Szenen (optional)

Eine Szene pro Zeile. Dann entsteht pro Zeile ein Bild, kombiniert mit dem Thema oben – und die Zeile wird automatisch zum Seitentext. Beispiel: Thema „Die Wikinger" + Szenen „bei der Jagd", „beim Fischen" … Die Bildanzahl richtet sich dann nach der Zeilenzahl.
